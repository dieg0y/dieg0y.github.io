CARPETA DE CERTIFICADOS (PDF)
=============================

Dejá acá los PDF de tus certificados y la web los muestra DIRECTO EN LA
PÁGINA (sin que nadie tenga que descargar nada) usando el visor integrado.

NOMBRES EXACTOS QUE LA WEB ESPERA
---------------------------------
- Certificado de Cambridge (Linguaskill):
    linguaskill-diego-yonoff.pdf

- El CV NO va acá: ya vive en public/cv-diego-yonoff-iam.pdf

- Certificados nuevos (SC-300, Security+, etc.):
    cuando los obtengas, guardalos en minúsculas y con guiones, por ejemplo:
    sc300-diego-yonoff.pdf
    y avisale al asistente para conectarle un botón "View certificate".

CÓMO SUBIRLO
------------
1. Arrastrá el PDF a esta carpeta.
2. git add public/certs/ → git commit → git push.
3. Listo: el botón "View certificate" lo abre enseguida en la página.

Mientras el PDF no exista, el botón muestra el reporte detallado de
puntajes (el modal) — o sea, nada se rompe si todavía no lo subiste.
